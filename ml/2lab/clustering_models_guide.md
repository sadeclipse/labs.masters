# Методы кластеризации: K-Means, DBSCAN и иерархическая кластеризация

## 1. Что такое кластеризация

Кластеризация — это задача обучения без учителя, в которой нужно разбить объекты на группы (кластеры) так, чтобы объекты внутри одной группы были похожи друг на друга, а объекты из разных групп — отличались. В отличие от классификации, заранее известных меток классов нет: алгоритм сам находит структуру в данных.

Все три рассматриваемых метода решают одну и ту же задачу, но делают разные предположения о том, что такое «хороший кластер»:

- K-Means ищет компактные группы вокруг центроидов;
- DBSCAN ищет области высокой плотности и отдельно выделяет шум;
- иерархическая кластеризация строит дерево последовательных объединений объектов.

## 2. Метод K-средних (K-Means)

### 2.1. Идея метода

K-Means предполагает, что кластер — это компактная группа объектов вокруг некоторого центра (центроида). Алгоритм заранее получает число кластеров `k` и старается подобрать такие центроиды, чтобы суммарное квадратичное расстояние от объектов до своих центроидов было минимальным.

Целевая функция (инерция):

```
J = Σ_i ||x_i − μ_{c(i)}||²
```

где `x_i` — объект, `μ_{c(i)}` — центроид кластера, к которому отнесён объект, `c(i)` — номер этого кластера.

### 2.2. Как работает алгоритм под капотом

Классический алгоритм Ллойда состоит из следующих шагов:

1. Задать число кластеров `k`.
2. Инициализировать `k` центроидов.
3. Для каждого объекта вычислить расстояние до всех центроидов и отнести объект к ближайшему.
4. Для каждого кластера пересчитать центроид как среднее арифметическое всех его объектов:
   ```
   μ_j = (1 / |C_j|) · Σ_{x_i ∈ C_j} x_i
   ```
5. Повторять шаги 3–4, пока центроиды не перестанут заметно смещаться или пока не закончится число итераций.

Алгоритм гарантированно сходится к локальному минимуму инерции, но не обязательно к глобальному. Поэтому результат зависит от начальной инициализации и числа `k`.

Сложность одной итерации — примерно `O(n · k · d)`, где `n` — число объектов, `k` — число кластеров, `d` — размерность признаков. На практике K-Means работает быстро и хорошо масштабируется.

### 2.3. Инициализация центроидов

- **random** — центроиды выбираются случайно из данных или случайно в пространстве признаков. Просто, но может привести к плохому локальному оптимуму.
- **k-means++** — первый центроид выбирается случайно, затем каждый следующий выбирается с вероятностью, пропорциональной квадрату расстояния до ближайшего уже выбранного центроида. Это уменьшает риск неудачной инициализации.
- **farthest-first** — каждый следующий центроид выбирается как объект, наиболее удалённый от уже выбранных центроидов. Даёт хорошее покрытие пространства, но может быть чувствителен к выбросам.

Параметр `n_init` задаёт число независимых запусков с разной инициализацией. Итоговым считается решение с наименьшей инерцией. В новых версиях scikit-learn по умолчанию используется `n_init='auto'`.

### 2.4. Как выбрать число кластеров k

**Метод локтя.** Строят график зависимости инерции `J` от `k`. С ростом `k` инерция всегда убывает, поэтому ищут «локоть» — точку, после которой дальнейшее увеличение `k` даёт малое улучшение. Если явного излома нет, метод локтя не даёт однозначного ответа.

**Силуэтный анализ.** Для каждого объекта `i` считают:

```
a(i) = среднее расстояние до объектов своего кластера
b(i) = среднее расстояние до объектов ближайшего чужого кластера
s(i) = (b(i) − a(i)) / max(a(i), b(i))
```

Значение `s(i)` лежит в диапазоне от −1 до 1:

- `s(i) ≈ 1` — объект хорошо лежит в своём кластере;
- `s(i) ≈ 0` — объект на границе кластеров;
- `s(i) < 0` — объект, скорее всего, отнесён не к своему кластеру.

Средний силуэт по всем объектам используют для выбора `k`: выбирают значение, при котором средний силуэт максимален. Полный расчёт силуэта требует попарных расстояний, поэтому на больших данных его считают по подвыборке (в scikit-learn это параметр `sample_size`).

### 2.5. Ансамблевая кластеризация на основе K-Means

Один запуск K-Means может попасть в неудачный локальный оптимум. Чтобы повысить устойчивость, запускают алгоритм много раз с разной инициализацией и объединяют результаты:

1. Выполняют `M` запусков K-Means.
2. Для каждой пары объектов считают, как часто они попадали в один кластер. Получается матрица совместной встречаемости (co-association matrix).
3. По матрице `1 − coassociation` выполняют иерархическую кластеризацию (например, average linkage) и получают итоговое разбиение.

Такой подход называется consensus clustering или evidence accumulation clustering. Он не гарантирует улучшения внешних метрик, но снижает зависимость от одного случайного запуска.

### 2.6. Гиперпараметры K-Means в scikit-learn

| Параметр | Что задаёт | Типичные значения |
|---|---|---|
| `n_clusters` | Число кластеров `k` | 2–10, подбирается по локтю/силуэту |
| `init` | Способ инициализации | `'k-means++'`, `'random'`, массив центроидов |
| `n_init` | Число запусков с разной инициализацией | `10`, `'auto'` |
| `max_iter` | Максимум итераций одного запуска | `300` |
| `tol` | Порог остановки по изменению центроидов | `1e-4` |
| `algorithm` | Реализация | `'lloyd'`, `'elkan'` |
| `random_state` | Фиксация случайности | любое целое число |

### 2.7. Плюсы и минусы

**Плюсы:** быстрый, простой, хорошо масштабируется, легко интерпретируется, работает на больших данных.

**Минусы:** нужно заранее задавать `k`; предполагает компактные кластеры примерно одинакового размера; чувствителен к масштабу признаков, выбросам и инициализации; плохо работает с кластерами сложной формы.

### 2.8. Пример кода

```python
from sklearn.cluster import KMeans

model = KMeans(
    n_clusters=4,
    init="k-means++",
    n_init=10,
    max_iter=300,
    random_state=42,
)
labels = model.fit_predict(X_scaled)
print(model.inertia_)
```

## 3. DBSCAN

### 3.1. Идея метода

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) ищет кластеры как области высокой плотности, разделённые областями низкой плотности. В отличие от K-Means, число кластеров заранее не задаётся, а объекты в разреженных областях могут быть отнесены к шуму.

### 3.2. Основные определения

Для точки `p` и параметров `eps` и `min_samples`:

- **eps-окрестность** — множество точек, расстояние от которых до `p` не больше `eps`;
- **core point (ядровая точка)** — точка, в eps-окрестности которой не меньше `min_samples` точек (включая саму точку);
- **border point (граничная точка)** — точка, которая не является ядровой, но попадает в eps-окрестность некоторой ядровой точки;
- **noise point (шум)** — точка, которая не является ни ядровой, ни граничной;
- **density-reachable** — точка `q` достижима по плотности из `p`, если существует цепочка ядровых точек, в которой каждая следующая лежит в eps-окрестности предыдущей;
- **density-connected** — две точки связаны по плотности, если существует точка, из которой обе достижимы по плотности.

Кластер — это максимальное множество точек, связанных по плотности. Все точки, не попавшие ни в один кластер, получают метку `-1` (шум).

### 3.3. Как работает алгоритм под капотом

1. Для каждой точки найти всех соседей в радиусе `eps`.
2. Если точка имеет не меньше `min_samples` соседей, она ядровая.
3. Из каждой ядровой точки запустить обход по плотности: добавлять в кластер все достижимые ядровые и граничные точки.
4. Точки, которые не были достигнуты ни из одной ядровой точки, пометить как шум.

Сложность зависит от структуры данных и индекса. С пространственным индексом (kd-tree, ball tree) в среднем она близка к `O(n log n)`, в худшем случае — `O(n²)`. На больших размерностях индексы работают хуже, и DBSCAN может замедляться.

### 3.4. Как подобрать eps и min_samples

**min_samples** обычно выбирают по размерности данных: чем больше признаков и чем больше шума, тем больше `min_samples`. Часто берут `min_samples ≈ 2 · d` или не меньше `d + 1`, где `d` — размерность. На практике проверяют несколько значений: 5, 10, 20, 40.

**eps** подбирают по графику k-расстояний:

1. Для каждого объекта считают расстояние до `k`-го ближайшего соседа (`k = min_samples`).
2. Расстояния сортируют по возрастанию и строят график.
3. Ищут «колено» — точку, после которой расстояние резко растёт. Значение `eps` в районе колена считают хорошей отправной точкой.

Если `eps` слишком мал, почти все точки становятся шумом или образуют много мелких кластеров. Если `eps` слишком велик, все точки сливаются в один кластер.

### 3.5. Чувствительность к шуму и выбросам

DBSCAN устойчив к выбросам в том смысле, что явные выбросы обычно получают метку шума и не влияют на центроиды кластеров. Однако:

- при слишком большом `eps` выбросы могут «прилипнуть» к кластеру;
- при слишком маленьком `eps` в шум уйдёт слишком много полезных объектов;
- DBSCAN плохо работает, если кластеры имеют сильно разную плотность: один `eps` не может быть оптимальным для всех кластеров;
- результат зависит от масштаба признаков, поэтому перед запуском нужно стандартизировать данные.

### 3.6. Гиперпараметры DBSCAN в scikit-learn

| Параметр | Что задаёт | Типичные значения |
|---|---|---|
| `eps` | Радиус eps-окрестности | подбирается по k-расстояниям, например 0.3–2.0 |
| `min_samples` | Минимум точек в eps-окрестности для ядровой точки | 5, 10, 20, 40 |
| `metric` | Метрика расстояния | `'euclidean'`, `'manhattan'`, `'cosine'` |
| `algorithm` | Алгоритм поиска соседей | `'auto'`, `'ball_tree'`, `'kd_tree'`, `'brute'` |
| `leaf_size` | Размер листа для tree-алгоритмов | `30` |
| `n_jobs` | Число потоков | `-1` |

### 3.7. Плюсы и минусы

**Плюсы:** не нужно задавать число кластеров; находит кластеры произвольной формы; явно выделяет шум; устойчив к выбросам при удачных параметрах.

**Минусы:** чувствителен к `eps` и `min_samples`; плохо работает при разной плотности кластеров; качество падает в пространствах высокой размерности; на больших данных может быть медленным.

### 3.8. Пример кода

```python
from sklearn.cluster import DBSCAN

model = DBSCAN(
    eps=1.7,
    min_samples=10,
    metric="euclidean",
)
labels = model.fit_predict(X_scaled)
print("Шум:", (labels == -1).mean())
```

## 4. Иерархическая кластеризация

### 4.1. Идея метода

Иерархическая кластеризация строит последовательность вложенных разбиений. В агломеративном варианте (снизу вверх) каждый объект сначала считается отдельным кластером, затем на каждом шаге два ближайших кластера объединяются, пока не останется один кластер или не будет достигнут нужный уровень.

Результат удобно изображать в виде дендрограммы — дерева, по которому можно выбрать число кластеров, разрезав его на нужной высоте.

### 4.2. Как работает алгоритм под капотом

1. Каждый объект — отдельный кластер.
2. Вычислить матрицу расстояний между объектами.
3. Найти пару кластеров с минимальным расстоянием.
4. Объединить эту пару в один кластер.
5. Пересчитать расстояния от нового кластера до остальных.
6. Повторять шаги 3–5, пока не останется один кластер.

Ключевой вопрос — как измерять расстояние между кластерами. Для этого используются различные методы связи (linkage).

### 4.3. Метрики расстояния

- **Евклидово расстояние** — прямое расстояние между точками:
  ```
  d(x, y) = sqrt(Σ_j (x_j − y_j)²)
  ```
- **Манхэттенское расстояние** (cityblock) — сумма абсолютных разностей координат:
  ```
  d(x, y) = Σ_j |x_j − y_j|
  ```
- **Косинусное расстояние** — измеряет угол между векторами и часто используется для текстовых или разреженных данных:
  ```
  d(x, y) = 1 − (x · y) / (||x|| · ||y||)
  ```

### 4.4. Методы связи (linkage)

- **single linkage** — расстояние между кластерами равно минимальному расстоянию между их объектами. Может выделять кластеры сложной формы, но сильно страдает от эффекта цепочки (chaining): кластеры «вытягиваются» через цепочки близких точек.
- **complete linkage** — расстояние равно максимальному расстоянию между объектами кластеров. Даёт более компактные кластеры, но чувствителен к выбросам.
- **average linkage** — среднее расстояние между всеми парами объектов из двух кластеров. Компромисс между single и complete.
- **Ward linkage** — объединяет кластеры так, чтобы минимально увеличить внутрикластерную дисперсию. Обычно работает хорошо для компактных кластеров, но требует евклидова расстояния.

### 4.5. Выбор числа кластеров по дендрограмме

По вертикальной оси дендрограммы откладывается расстояние объединения. Чтобы получить `k` кластеров, нужно провести горизонтальную линию на такой высоте, чтобы она пересекла ровно `k` вертикальных ветвей. Обычно выбирают высоту перед большим скачком расстояния: если следующее объединение происходит гораздо выше предыдущего, это хорошее место для разреза.

### 4.6. Масштабируемость

Классическая агломеративная кластеризация требует хранить матрицу расстояний размера `n × n`, поэтому:

- время работы в общем случае — `O(n² log n)` или `O(n²)` в зависимости от реализации;
- память — `O(n²)`.

Из-за этого метод плохо подходит для сотен тысяч объектов. На больших данных его применяют к подвыборкам, к агрегированным объектам или используют приближённые версии (например, BIRCH). В лабораторной работе это хорошо видно по росту времени: при увеличении объёма данных время растёт квадратично.

### 4.7. Гиперпараметры иерархической кластеризации в scikit-learn

| Параметр | Что задаёт | Типичные значения |
|---|---|---|
| `n_clusters` | Число кластеров, на которое нужно разрезать дерево | 2–10 |
| `metric` | Метрика расстояния | `'euclidean'`, `'manhattan'`, `'cosine'` |
| `linkage` | Метод связи | `'ward'`, `'complete'`, `'average'`, `'single'` |
| `distance_threshold` | Порог разреза дендрограммы вместо `n_clusters` | подбирается по дендрограмме |
| `compute_distances` | Вычислять ли расстояния для дендрограммы | `True` / `False` |

### 4.8. Плюсы и минусы

**Плюсы:** не нужно заранее задавать число кластеров (можно выбрать по дендрограмме); наглядный результат; можно использовать разные метрики и методы связи; хорошо работает на небольших и средних данных.

**Минусы:** высокая вычислительная сложность и память `O(n²)`; чувствительность к выбросам и выбору linkage; результат зависит от метрики расстояния; на больших данных напрямую неприменим.

### 4.9. Пример кода

```python
from scipy.cluster.hierarchy import dendrogram, fcluster, linkage

Z = linkage(X_scaled, method="average", metric="euclidean")
labels = fcluster(Z, t=4, criterion="maxclust") - 1
dendrogram(Z)
```

## 5. Сравнение методов

| Критерий | K-Means | DBSCAN | Иерархическая |
|---|---|---|---|
| Число кластеров | задаётся заранее | определяется автоматически | выбирается по дендрограмме |
| Форма кластеров | компактная, близкая к сферической | произвольная | зависит от linkage |
| Шум и выбросы | не выделяет, чувствителен | явно выделяет шум | чувствительна к выбросам |
| Масштабируемость | высокая | средняя | низкая, `O(n²)` |
| Чувствительность к инициализации | есть | нет | нет |
| Основные гиперпараметры | `n_clusters`, `init`, `n_init` | `eps`, `min_samples` | `linkage`, `metric`, `n_clusters` |
| Когда использовать | большие данные, компактные кластеры | кластеры сложной формы, есть шум | небольшие данные, нужна наглядность |

## 6. Что показала лабораторная работа

На датасете Perfume Type Classification:

- K-Means лучше всего согласуется с реальными классами среди четырёхкластерных решений: ARI ≈ 0,32, NMI ≈ 0,41. Кластеры упорядочены по концентрации, стойкости и цене, то есть метод нашёл содержательную структуру.
- DBSCAN выделил четыре кластера и около 0,5% шума, но его согласие с реальными классами близко к нулю: плотностная структура данных не совпадает с категориями ароматов. При этом искусственные выбросы DBSCAN относит к шуму практически на 100%.
- Иерархическая кластеризация с complete linkage даёт ARI ≈ 0,21–0,26, а single linkage страдает от эффекта цепочки. Время работы растёт квадратично, поэтому на полном наборе из 55 000 объектов метод требует слишком много памяти.

Главный вывод: выбор алгоритма зависит не только от данных, но и от того, что считается «хорошим кластером». Внутренние метрики (silhouette, инерция) оценивают геометрию разбиения, а внешние (ARI, NMI, purity) — совпадение с реальными классами. Эти оценки могут расходиться, поэтому результаты кластеризации всегда нужно интерпретировать содержательно.
